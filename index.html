📋 Step 1 — Create Supabase Table
Run this SQL in your Supabase project → SQL Editor. Only needed once.
CREATE TABLE capi_events_log ( id bigserial PRIMARY KEY, lead_id text NOT NULL, status_id integer NOT NULL, event_name text NOT NULL, phone_hash text, meta_response text, sent_at timestamptz DEFAULT now(), UNIQUE(lead_id, status_id) ); -- Index for fast dashboard queries CREATE INDEX idx_capi_sent_at ON capi_events_log(sent_at DESC); CREATE INDEX idx_capi_event_name ON capi_events_log(event_name);
🔑 Step 2 — Railway Environment Variables
Paste your keys below. Click "Copy for Railway" to get a formatted output you can paste into Railway's variable editor.
METABASE_API_KEY
PIXEL_ID
CAPI_ACCESS_TOKEN
SUPABASE_ANON_KEY
🚀 Step 3 — Deploy to Railway
1. Push all Node.js files to a GitHub repo named terratern-capi
2. Go to railway.app → New Project → Deploy from GitHub
3. Add the 4 environment variables above in Railway → Variables tab
4. Start command: node index.js
5. Watch the Railway logs — you should see the first pull within seconds
